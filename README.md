# ha-addon-pihole

Home Assistant add-on repository for **Pi-hole v6** — network-wide ad blocking via DNS.

## Installation

In Home Assistant: **Settings → Add-ons → Add-on Store → ⋮ → Repositories**, add:

```
https://github.com/chrisleech/ha-addon-pihole
```

Then find **Pi-hole** in the store and install.

## Add-ons

| Add-on | Description |
|---|---|
| [Pi-hole](pihole/) | Pi-hole v6 with full HA sidebar panel support |
